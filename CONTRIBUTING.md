# Contributing to Loams desktop

Fork and branch from `dev`, then open a pull request against `dev`. `main` is the release branch. Keep PRs focused, include tests for behavior changes, and sign off every commit with `git commit -s`. Use merge commits after CI and review pass.

Anyone may contribute. After a first merged PR, a team maintainer may add the contributor to `committers`. Committers may merge into `dev`; maintainers merge `dev` into `main`. See [GOVERNANCE.md](GOVERNANCE.md) for the contributor ladder.

Follow the Loams [Code of Conduct](https://github.com/ostrium-labs/loams/blob/main/CODE_OF_CONDUCT.md) and [security policy](https://github.com/ostrium-labs/loams/blob/main/SECURITY.md). Propose ecosystem changes in [Loams Discussions](https://github.com/ostrium-labs/loams/discussions) and an RFC issue before opening implementation PRs.
